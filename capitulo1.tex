\chapter{Introducción}\label{cap1}

\section{Objetivos}
\textbf{Objetivo General}\\
Diseñar y construir un mecanismo que realice, de manera automática, la limpieza de una hilera de paneles solares tales como las encontradas en granjas solares.\\
\textbf{Objetivos Específicos}
\begin{enumerate}
    \item Diseñar un modelo CAD del mecanismo que se utilizara para el movimiento del limpiador sobre los paneles solares.
    \item Realizar las distintas simulaciones de esfuerzos y movimiento con un software CAE.
    \item Construir y ensamblar una estructura adecuada para el movimiento del mecanismo sobre los paneles solares; que tenga dimensiones similares al estándar de los paneles solares.
    \item Diseño y construcción del sistema electrónico.
    \item Acoplar una forma de alimentación autónoma para el mecanismo.
    \item Implementar sensores para la correcta limpieza de los paneles solares.
    \item Acoplamiento de sensores para el monitoreo de las condiciones externas al panel, que pueden afectar el proceso de limpieza.
    \item Diseño de la interfaz usuario-máquina.
\end{enumerate}
